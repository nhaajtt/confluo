Download manager for Windows · free

Every network you have, woven into one download.

Weft splits one file into many streams and sends them over every network your PC has: Ethernet, Wi-Fi, a phone hotspot. If the power or the connection drops, it carries on from where it stopped, and it always tells you what is holding the speed back.

01 · How it works

Four things Weft does differently

A

More streams only when they help

It starts with 8 connections, measures, and goes to 16 or 32 only if the speed really follows. When a server says no, it steps back and asks again a second later instead of hammering.

B

Every network at once

Each connection is pinned to its own adapter, so Ethernet and Wi-Fi really carry the same file together. The faster one takes the larger share; if one drops, the others take over its part.

C

A crash is not a restart

Twice a second Weft records which bytes are safely on disk. In testing the process was killed 11 times and the server taken away once during a 1 GB file: the result was still byte-exact.

D

It says what is slow

The network path, a server that caps each connection, a server refusing connections, the disk, or your own limit: the app names the one cause instead of leaving you to guess.

03 · Browser

Click download in the browser, Weft takes it

The companion extension hands downloads from Chrome, Edge or Firefox to Weft. It talks to exactly one address: 127.0.0.1 on your own PC.

  • Paired with a code that exists only on your PC. The code is never sent: each side only proves it knows it.
  • Web pages cannot reach Weft; any request with a web origin is refused.
  • If Weft is not running, the browser downloads as usual. Nothing is ever fetched twice.
  • Tested in real Chromium 156 and Firefox 160.

04 · FAQ

Short questions, straight answers

Is it free?

Yes. No account, no ads, no paid tier. The source is under the MIT licence.

Do two networks make it twice as fast?

Only when they are two different internet lines, such as home fibre plus a phone's 4G. Ethernet and Wi-Fi on the same router are still one line; Weft notices that and tells you.

Windows shows a warning when I install. Is that expected?

It can. The installer is not code-signed yet, so SmartScreen may ask you to confirm. The install command above checks the installer's SHA-256 before running it.

Does it do torrents or streaming-site videos?

No. Weft downloads files over HTTP and HTTPS and tries to do that one thing well.

Is there a macOS or Linux version?

Not as an app yet. The engine is written for all three systems, but only the Windows build has been tested in full so far.

How do I uninstall it?

Settings, Apps, Weft, Uninstall. The program files and the Start Menu entry go; the files you downloaded stay.
