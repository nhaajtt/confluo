FAQ

Short questions, straight answers

Is it free?

Yes. No account, no ads, no paid tier. The source is under the MIT licence, on GitHub.

Do two networks make it twice as fast?

Only when they are two different internet lines, such as home fibre plus a phone's 4G. Ethernet and Wi-Fi on the same router are still one line; Confluo notices that and tells you.

Why does Windows warn me?

The installer is not code-signed yet, so SmartScreen may ask: More info, then Run anyway. The one-line install checks the installer's SHA-256 before running it.

Does it do torrents or streaming-site videos?

No. Confluo downloads files over HTTP and HTTPS and tries to do that one thing well.

Is there a macOS or Linux version?

Not as an app yet. The engine is written for all three systems, but only the Windows build has been tested in full so far.

How do I uninstall it?

Settings, Apps, Confluo, Uninstall. The program files and the Start Menu entry go; the files you downloaded stay.
